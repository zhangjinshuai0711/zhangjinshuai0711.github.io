01 Scalable Tool Calling

Findings of EMNLP 2025 · Second author

Toolscaler

Contributed to a generative tool-calling framework that encodes 46,985 tools as composable, structure-aware semantic code sequences. Built high-quality training data from ToolBench documentation, query-tool pairs, and invocation trajectories, then evaluated retrieval, unseen-tool generalization, and end-to-end calling.

02 Graph Anomaly Detection

First author · Manuscript in preparation, target: IEEE TDSC

FGAD

Designed feedback-guided anomalous diffusion suppression to prevent abnormal information from contaminating neighboring node representations. The model achieved the best AUC on seven of eight evaluated datasets against eleven baselines, including 91.68% on Inj Flickr.
