# zhangjinshuai0711.github.io

Bilingual personal homepage for Jinshuai Zhang.

## Preview

Run `python3 -m http.server 4173` and open `http://127.0.0.1:4173/`.

## Verify

Run `node tests/site-contract.mjs` and `node --check assets/js/main.js`.

## Deploy

GitHub Pages publishes the `main` branch at `https://zhangjinshuai0711.github.io/`.
